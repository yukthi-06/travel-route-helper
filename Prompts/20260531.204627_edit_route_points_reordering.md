# Implementation Plan - Edit Route Points Re-ordering

We will implement an edit mode on the route screen (`RouteDetailsActivity`) where users can re-order points using visual drag-and-drop.

## Key Goals
1. Add an "Edit" option/button to the route screen's toolbar.
2. Introduce an "Edit Mode" in `RouteDetailsActivity` and `PointAdapter`.
3. In "Edit Mode":
   - Disable GPS live updates and the dynamic distance-based re-ordering of points.
   - Display the active points in their sequential linked-list order (without the "Current User" status row).
   - Add a visual drag handle or drag icon on the items in the list.
   - Use Android's standard `ItemTouchHelper` to support drag-and-drop re-ordering in the `RecyclerView`.
4. When the user completes re-ordering and clicks "Done":
   - Re-arrange the list of points in the `Route` model.
   - Save the route to disk (which automatically updates the `parentId` and `childId` pointers).
   - Exit Edit Mode and resume normal GPS tracking / dynamic distance-based re-ordering.
5. If the user exits Edit Mode without saving (e.g. by clicking "Cancel" or pressing back), discard the changes and restore normal mode.

---

## Detailed Components to Modify/Create

### 1. Resource Files
- **`menu_route_details.xml`**:
  Create a new menu file containing:
  - An "Edit" button (shows in normal view mode).
  - A "Done" button (shows in edit mode).
  - A "Cancel" button (shows in edit mode).
- **`item_point.xml`**:
  Add a drag handle icon (e.g., standard reorder / drag handle icon) that is visible only in Edit Mode to guide the user.

### 2. `PointAdapter.java`
- Introduce a boolean `isEditMode` flag.
- When `isEditMode` is true:
  - `getItemCount()` should return only the count of the points (no `Current Location` row).
  - `getItemViewType(position)` should always return `TYPE_POINT`.
  - In `onBindViewHolder`, we directly bind the point at `position`.
  - Show the drag handle icon on `PointViewHolder`.
  - Disable GPS dynamic sorting updates in `updateCurrentLocation` (if it gets called).
- Add helper methods:
  - `setEditMode(boolean editMode)` to toggle edit mode, fetch the original route order, and trigger a list refresh.
  - `onItemMove(int fromPosition, int toPosition)` to swap items in the displayed list during drag-and-drop.
  - `getPointsList()` to retrieve the current state of the points.

### 3. `RouteDetailsActivity.java`
- Override `onCreateOptionsMenu` and `onOptionsItemSelected` to inflate the new `menu_route_details.xml` menu and handle clicks.
- Manage the `isEditMode` state in the activity.
- Initialize `ItemTouchHelper` and attach it to the `RecyclerView` when in Edit Mode.
- Define a custom `ItemTouchHelper.SimpleCallback` that:
  - Supports upward and downward drag gestures.
  - Disables swipe actions.
  - Delegates item swaps to `PointAdapter.onItemMove(from, to)`.
- When "Done" is clicked:
  - Get the re-ordered points list from the adapter.
  - Reconstruct the `currentRoute` points list (reordered active points + deleted points).
  - Call `FileUtils.saveRoute(this, currentRoute)` to persist the new order.
  - Toggle `isEditMode = false` and reload the route data normally.
- When "Cancel" is clicked:
  - Toggle `isEditMode = false` and reload original route data normally.
- Handle physical back button press: if in Edit Mode, exit Edit Mode (optionally cancel or ask to save, cancelling is safer/simpler).
