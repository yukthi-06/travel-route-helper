# User Prompt
```
All routes to be saved and loaded from /sdcard/Vypeensoft/Travel_Route_Helper/routes/
All setings to be saved and loaded from /sdcard/Vypeensoft/Travel_Route_Helper/settings/setings.json
```

## Overview
We need to update the storage locations for both routes and settings in the app to match the requested absolute filesystem paths under `/sdcard/Vypeensoft/Travel_Route_Helper/`:
1. **Routes**: Save and load all route JSON files under `/sdcard/Vypeensoft/Travel_Route_Helper/routes/`.
2. **Settings**: Save and load all configuration settings in a JSON file under `/sdcard/Vypeensoft/Travel_Route_Helper/settings/setings.json`.

## Implementation Details

### 1. Update `FileUtils.java`
- Modify `getRoutesDirectory()` to append a `"routes"` subdirectory under the main `"Travel_Route_Helper"` folder.
- This ensures all routes list and save actions automatically resolve to `/sdcard/Vypeensoft/Travel_Route_Helper/routes/`.

### 2. Update `SettingsManager.java`
- Rewrite `SettingsManager` to read/write using `Gson` and standard file operations instead of `SharedPreferences`.
- Define the absolute target settings file path as `/sdcard/Vypeensoft/Travel_Route_Helper/settings/setings.json`.
- Implement safe loading/saving with directory creation support.
