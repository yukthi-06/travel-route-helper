# User Prompt
```
The points in a route should be treated as a type of linked list.  ie.. there is an order of points.
The json file should be updated with parent point's ID.  
Also we can consider if child Point's ID also needs to be maintained... may be like a doubly linked list.
On loading a JSON, if there is no order maintained(ie.. if parent id or child id is not present), then th ejson has to be updated with parentid and child id, using the order of points in the json....
```

## Overview
We need to implement a doubly linked list structure for the points in a Route. Each point in a Route will maintain its parent point's ID (`parentId`) and child point's ID (`childId`). When a JSON file is loaded or saved, we want to ensure these pointers are fully consistent with the order of active (non-deleted) points in the route. If a loaded JSON lacks these pointers, they will be automatically generated, and the JSON file will be updated on disk.

## Proposed Changes

### 1. Update `Point.java`
- Add two new private String fields: `parentId` and `childId`.
- Add getters and setters for these fields.
- Initialize them to `null` by default.
- Since Gson uses reflection to serialize and deserialize fields, these fields will automatically be populated from and written to the JSON file.

### 2. Update `Route.java`
- Add a helper method `updateLinkedPointers()`:
  - This method filters out any deleted points (i.e. `p.isDeleted() == true`), setting their `parentId` and `childId` to `null`.
  - For active points, it computes the expected `parentId` (the ID of the previous active point) and `childId` (the ID of the next active point).
  - It compares these expected values against the current values and updates them if they differ.
  - It returns `true` if any change was made, `false` otherwise.

### 3. Update `FileUtils.java`
- In `saveRoute(Context context, Route route)`:
  - Before writing to the JSON file, invoke `route.updateLinkedPointers()` to ensure the saved JSON is always fully linked and consistent.
- In `loadRoute(File file)`:
  - After deserializing the `Route`, call `route.updateLinkedPointers()`.
  - If `updateLinkedPointers()` returns `true` (meaning parent or child pointers were missing or incorrect), save the route back to the JSON file immediately to persist the updated pointers.
