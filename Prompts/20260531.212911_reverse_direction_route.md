# Implementation Plan - Reverse Route Direction

We will implement a "Reverse Direction" option inside the Route screen's overflow menu. This option will reverse the route sequence and automatically rename and relocate the saved file under the reversed route name.

## Key Goals
1. Add a "Reverse Direction" item (`action_reverse`) to `menu_route_details.xml` inside the overflow section.
2. Add `setRouteName()` setter to `Route.java`.
3. Handle click of "Reverse Direction" in `RouteDetailsActivity.java`:
   - Reverse the sequence of active points in the route.
   - Calculate the reversed route name (e.g. "Delhi to Mumbai" -> "Mumbai to Delhi").
   - Update the route's name.
   - Delete the old JSON file and the old directory (if empty).
   - Save the new route JSON file and folder using the new name.
   - Update the active `filePath` state in the activity.
   - Refresh the Action Bar title and reload the list.
