# User Prompt
```
the distance should nevr show blueish color... it should either be red(receding points) or green(approaching points)
```

## Overview
The user requested that the distance color should never be blueish/turquoise. Instead, it should be strictly binary based on whether a point is receding or approaching:
- **Red (`#E57373`)** for receding points (points behind the user: `position < userRowPosition`).
- **Green (`#81C784`)** for approaching points (points ahead of the user: `position >= userRowPosition`).

We will remove the dynamic comparison logic and the default turquoise (`#4EC3D0`) fallback, and directly assign the color based on the point's position relative to the user.

## Implementation Details

### Changes to `PointAdapter.java`
In `bindPoint(PointViewHolder holder, int position)`:
- Replace the color assignment logic with a clean conditional check:
  ```java
  int color;
  if (position < userRowPosition) {
      color = Color.parseColor("#E57373"); // Red for receding points
  } else {
      color = Color.parseColor("#81C784"); // Green for approaching points
  }
  ```
