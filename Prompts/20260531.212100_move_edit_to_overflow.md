# Implementation Plan - Move Edit Route Option to Overflow Menu

We will move the "Edit" route option into an overflow menu (the standard three-dots menu on the toolbar).

## Key Goals
1. Modify `menu_route_details.xml` to set `app:showAsAction="never"` for the `action_edit` menu item. This automatically hides the item from the direct app bar and moves it inside a newly created standard overflow menu on the right.
2. Maintain `action_done` and `action_cancel` visible as direct app bar actions (`app:showAsAction="ifRoom|withText"`) when Edit Mode is active to keep save/cancel transitions immediate and user-friendly.

---

## Detailed Components to Modify

### 1. `menu_route_details.xml`
- Change `app:showAsAction` attribute of `action_edit` from `ifRoom|withText` to `never`.
