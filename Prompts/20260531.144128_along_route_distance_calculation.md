# User Prompt
```
Calculate distance from curent point to a Point in the list is done like this...
Calculate the distance from the current point to the nearest passed point.  Add that to the distance from previous two points.  Add that to its previous points....

Example:  lets assume points in list like this
Point A
Point B
Point C
I am here...
Point D
Point E

In above case... my distance to Point A is calculated by adding distance between current location and Point C
Add that to distance beween Point C and B
Add that to distance between Point B and A.

Similarley distance to POint E is calulated by getting distance between Current point and Point D.  Add that to distance between Point D and E.
```

## Overview
We need to calculate the user's distance to any point along the route by walking the path sequentially rather than calculating straight-line distances.
Specifically:
- Receding points (indices `j <= minIndex`): the distance is the straight-line distance from the user to the nearest passed point (`P_minIndex`) plus the cumulative segment lengths from `P_j` to `P_minIndex`.
- Approaching points (indices `j > minIndex`): the distance is the straight-line distance from the user to the nearest ahead point (`P_minIndex+1`) plus the cumulative segment lengths from `P_minIndex+1` to `P_j`.

## Proposed Changes

### 1. Update `PointAdapter.java`
- Modify `updateCurrentLocation(Location currLocation)`:
  - First, compute the **direct straight-line distance** from `currLocation` to each active point, saving them in a temporary array `directDistances`.
  - Determine the user's placement `minIndex` using these direct distances (since placement is based on adjacent-pair direct distances).
  - Categorize points into `receding` and `approaching` sets in their original order.
  - Calculate **along-the-route distances** for `currentDistances`:
    - For receding points, sum the straight-line distance to `P_minIndex` and the route segment distances from `P_j` to `P_minIndex`.
    - For approaching points, sum the straight-line distance to `P_minIndex+1` and the route segment distances from `P_minIndex+1` to `P_j`.
  - Reassemble the points list with the user marker and notify change.
