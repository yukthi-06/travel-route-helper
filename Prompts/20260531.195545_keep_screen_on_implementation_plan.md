# User Prompt
Dont allow the mobile to sleep when app is running

# Implementation Plan - Keep Screen Awake

This plan outlines the changes needed to prevent the mobile device from sleeping while the application is in use. We will add a settings toggle "Keep Screen Awake" (enabled by default) and apply the `FLAG_KEEP_SCREEN_ON` window flag to all application activities.

## 1. Objectives
- Implement a user preference to toggle whether the screen should remain awake.
- Enable "Keep Screen Awake" by default.
- Dynamically apply the `WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON` flag to the current window in the lifecycle of the app's activities (`onResume()`) based on this preference.
- Provide a clean setting switch in the Settings UI so users can customize this behavior.

## 2. Proposed Changes

### A. Settings Resource Modifications
Modify `app/src/main/res/values/strings.xml` to include string resources for the new setting.
```xml
    <string name="label_keep_screen_on">Keep Screen Awake</string>
    <string name="summary_keep_screen_on">Prevent the mobile device from sleeping while the app is active.</string>
```

### B. Settings Storage Integration
Extend `com.vypeensoft.routehelper.utils.SettingsManager` to add:
- `boolean keepScreenOn = true;` inside `SettingsData` class.
- Getter and setter methods for `keepScreenOn`.

### C. Settings UI Update
Modify `app/src/main/res/layout/activity_settings.xml` to add a new section containing:
- A divider/separator.
- A labeled layout containing a `SwitchCompat` toggle for keeping the screen awake.

### D. Settings Activity Logic
Update `com.vypeensoft.routehelper.SettingsActivity` to:
- Bind the new `SwitchCompat` layout element.
- Load the initial state from `SettingsManager`.
- Set an `OnCheckedChangeListener` to save state and dynamically apply/clear the flag on the current window.

### E. Apply Across All Activities
Implement a helper method or apply logic inside `onResume()` of each active activity to dynamically enable or disable the wake-lock:
- `MainActivity`
- `RouteDetailsActivity`
- `AddPointActivity`
- `AboutActivity`

```java
    private void applyKeepScreenOnSetting() {
        if (new com.vypeensoft.routehelper.utils.SettingsManager(this).getKeepScreenOn()) {
            getWindow().addFlags(android.view.WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON);
        } else {
            getWindow().clearFlags(android.view.WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON);
        }
    }
```
In `onResume()`, invoke this helper method.
