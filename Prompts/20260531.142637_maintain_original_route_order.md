# User Prompt
```
the order of the points list should never change, only the current user placement within the list would change as the user travels...
```

## Overview
We need to ensure that the order of the points in the route display list never changes. Instead of sorting receding points by distance descending and approaching points by distance ascending, we will strictly preserve their original sequential route order. Only the current user placement (`----Current User----` marker row) will dynamically move and be positioned within the list as the user travels.

## Proposed Changes

### 1. Update `PointAdapter.java`
- In `updateCurrentLocation(Location currLocation)`:
  - Remove the calls to `Collections.sort(receding, ...)` and `Collections.sort(approaching, ...)`.
  - This ensures that both the `receding` and `approaching` sublists perfectly maintain their original route order as traversed in `orderedActive`.
  - The `currUserPoint` (divider row) is inserted exactly at `userRowPosition` (after `receding` and before `approaching`).
  - This preserves the exact real-world sequential order of the route while placing the user marker dynamically based on their progress.
