# User Prompt
```
I see sometimes that receding also is shown as green.  receding points should have the distance in red color.  
```

## Overview
We need to ensure that receding points (points that the user has already passed) always have their distance text colored red (`#E57373`), preventing them from being shown as green due to GPS jitter or dynamic distance comparisons.

## Proposed Changes

### 1. Update `PointAdapter.java`
- In `bindPoint(PointViewHolder holder, int position)`:
  - Check if the point is receding by comparing its list position to `userRowPosition` (`position < userRowPosition`).
  - If it is receding (`position < userRowPosition`), color it red (`#E57373`) unconditionally.
  - If it is approaching (`position >= userRowPosition`), retain the existing dynamic behavior where it is colored green (`#81C784`) if moving closer, red (`#E57373`) if moving away, or turquoise (`#4EC3D0`) by default.
