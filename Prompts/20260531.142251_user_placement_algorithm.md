# User Prompt
```
user's current point should be decided like this...
treat every adjacent points as "adjacent-point-pair"
Calculate the distance from current point to every adjaent pairs.
Take average of the two distance from each adjacent pair.
The adjacent pair, with the least average distance is the point where the current user is placed.
```

## Overview
We will implement an algorithm to determine the user's current position along the route by analyzing the adjacent point pairs in the original route order.
By computing the distance from the user's current GPS location to each active point and finding the adjacent pair with the minimum average distance, we can reliably place the user marker between the two points of that pair in the display list.

## Proposed Changes

### 1. Update `PointAdapter.java`
- Implement a helper method `getOriginalRouteOrder(List<Point> points)` to reconstruct the original sequential order of the active points using their doubly linked list `parentId` and `childId` pointers.
- In `updateCurrentLocation(Location currLocation)`:
  - Separate active points and calculate distances to each of them from `currLocation`.
  - Reconstruct the original route order of the active points using `getOriginalRouteOrder()`.
  - If there are 2 or more active points:
    - Iterate through every adjacent pair `(Point i, Point i+1)` and calculate the average distance from the user's location.
    - Identify the pair `minIndex` with the minimum average distance.
    - Classify points from index `0` to `minIndex` as `receding`.
    - Classify points from index `minIndex + 1` to `M - 1` as `approaching`.
  - If there is only 1 active point:
    - Place it in `receding` by default.
  - Sort the `receding` list by distance descending, and the `approaching` list by distance ascending, keeping the existing display preferences.
  - Set `userRowPosition` exactly at the boundary between the two groups.
  - Re-construct `this.pointsOnRoute` in the sorted order and call `notifyDataSetChanged()`.
