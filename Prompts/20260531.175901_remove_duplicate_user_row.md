# User Prompt
```
why have two similar rows in the list ?
One with "----Current User----" and another with "I am here"?
Just have the row with "I am here"
```

## Overview
Currently, the `PointAdapter` displays two rows representing the user's current location:
1. A normal list item with the name `"----Current User----"`.
2. A special custom card (`item_current_location.xml`) displaying `"I am here"`.

This redundancy occurs because:
- The previous implementation added a dummy `Point` named `"----Current User----"` to the `pointsOnRoute` list.
- At the same time, the adapter injected a special `TYPE_CURRENT_LOCATION` row at `userRowPosition` (which was set to `receding.size() + 1`).
- Since `"----Current User----"` was placed at `receding.size()`, its view type was resolved as `TYPE_POINT` (a normal point layout), while the next position was resolved as `TYPE_CURRENT_LOCATION`.

We will fix this by:
1. Removing the generation and insertion of the dummy `"----Current User----"` point from `pointsOnRoute` entirely.
2. Setting `userRowPosition` directly to `receding.size()`, so that the special `"I am here"` card is injected precisely between the receding and approaching points.
3. Cleaning up any unnecessary helper methods in `PointAdapter` related to managing the `"----Current User----"` dummy point.

## Implementation Details

### Changes to `PointAdapter.java`
- Modify `updateCurrentLocation(Location currLocation)`:
  - Remove construction of `currUserPoint` using `createCurrentUserPoint` and `addCurrentUserPoint`.
  - Remove `neutral` list.
  - Set `userRowPosition` to `receding.size()` (which is equivalent to the size of the `newOrder` list after adding all `receding` points).
  - Add only `receding` and `approaching` points to `newOrder`.
  - Simplify `initializeLinksIfMissing()` and `getOriginalRouteOrder()` since `"----Current User----"` is no longer part of `pointsOnRoute`.
- Remove the unused helper methods:
  - `createCurrentUserPoint(double lat, double lon)`
  - `addCurrentUserPoint(Point p)`
