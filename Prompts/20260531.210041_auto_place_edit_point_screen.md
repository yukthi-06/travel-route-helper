# Implementation Plan - Auto Place on Edit Point Screen

We will add an "Auto Place in Route" button to the Edit Point screen. This screen is managed by `AddPointActivity` when opened with a `POINT_ID` (Edit mode).

## Key Goals
1. Add an "Auto Place in Route" button to `activity_add_point.xml`.
2. Configure the button to be visible **only** in Edit mode (when `pointId != null`).
3. Position the button between the "Save Point" and "Delete Point" buttons.
4. Implement the auto-placement logic in `AddPointActivity.java` when the button is clicked:
   - Identify the point being edited.
   - Temporarily remove the point from the list of active points in the route.
   - Run the Minimum Path Increase insertion algorithm to find the optimal index in the remaining active points.
   - Re-insert the point at the optimal index in the route.
   - Save the updated route, show a success toast, and finish the activity.

### 2. `AddPointActivity.java`
- Declare the `buttonAutoPlace` field and find it by ID.
- In Edit mode (`pointId != null`):
  - Make `buttonAutoPlace` visible.
  - Set a click listener on `buttonAutoPlace`.
- Implement `autoPlacePoint()`:
  - Retrieve current input fields (name, categories, etc.) and keep the existing coordinates.
  - Extract all other active points in the route (excluding the one being edited).
  - Compute the optimal insertion index using the Minimum Path Increase algorithm.
  - Find the actual index of the target insertion slot within the full points list (which may contain deleted points).
  - Update and place the edited point at that optimal location in the route's list of points.
  - Call `FileUtils.saveRoute()` to persist the route and update its double-linked list pointers.
  - Finish the activity.
