# Goal
Enable auto-rotation in all directions (including upside-down portrait, regular portrait, and landscape) by changing the activity screen orientation settings to `fullSensor` in the Android Manifest, matching the implementation of GPS Location Logger.

## Proposed Changes

### Android Manifest

#### [MODIFY] [AndroidManifest.xml](file:///x:/Projects_X/0_Active/8_Android_APK/01_GPS/Travel_Route_Helper_APK_GITHUB/app/src/main/AndroidManifest.xml)
Modify the manifest to set `android:screenOrientation="fullSensor"` for all five activities:
- `MainActivity`
- `RouteDetailsActivity`
- `AddPointActivity`
- `SettingsActivity`
- `AboutActivity`

Optionally, add `android:configChanges="screenSize|smallestScreenSize|screenLayout|orientation"` to `MainActivity` if orientation changes need to be handled gracefully without restarting the activity, mirroring GPS Location Logger.
