# Implementation Plan

## Goal Description
Add a dynamic red banner displaying "GPS/Location not enabled" when the device's location services are disabled, within the `Travel_Route_Helper_APK_GITHUB` project.

## Proposed Changes

### UI Changes
- **File**: `app/src/main/res/layout/activity_main.xml`
- **Action**: Add a new `TextView` (`@+id/tv_no_gps`) representing the GPS banner immediately below the `MaterialToolbar`. It will have `android:visibility="gone"` by default. Background will be red (`#D32F2F`), text will be white. It will overlap or push the content below the toolbar.

### Logic Changes
- **File**: `app/src/main/java/com/vypeensoft/routehelper/MainActivity.java`
- **Action**: 
    - Declare `tvNoGps` and `gpsReceiver`.
    - In `onCreate()`, bind the `tvNoGps` TextView.
    - Implement `checkInitialGpsState()` to check the location state on startup using `LocationManager`.
    - Implement `setupGpsListener()` using a `BroadcastReceiver` for `LocationManager.PROVIDERS_CHANGED_ACTION` to dynamically show or hide the banner when the GPS state changes.
    - Unregister the receiver in a new `onDestroy()` method.

## Verification Plan
- Turn off GPS and verify the red banner appears below the toolbar on the main activity.
- Turn on GPS and verify the banner disappears.
