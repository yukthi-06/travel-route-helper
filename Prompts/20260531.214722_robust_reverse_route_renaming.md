# Implementation Plan - Robust Route Reversal & Atomic File System Renaming

We will enhance the "Reverse Direction" option to perform an atomic file system rename of both the route folder and JSON file on disk, mimicking the robust `renameTo()` pattern proven in `MainActivity.java`. This guarantees the route title, JSON file name, and directory name are all perfectly renamed and synchronized.

## Key Goals
1. Implement a more robust `getReversedRouteName()` to parse any variations of the "to" delimiter.
2. Use Android's atomic `File.renameTo()` first for the folder and then for the JSON file to prevent copy conflicts or locked file delete issues on the device.
3. Clean up any existing destination folder before renaming to prevent name conflicts.
4. Provide a solid direct file save/delete fallback if the atomic rename fails.
5. Safely update `filePath` and refresh the Action Bar title and RecyclerView lists.
